# CySec — Cybersecurity Knowledge Base

> Professional offensive security documentation for pentesters, red teamers, and security engineers.

## 🌐 Live Site
**[https://malik-azad.github.io/CySec](https://malik-azad.github.io/CySec)**

## 📚 Contents
- **Fundamentals** — Terminology, roles, security models, compliance, interview prep
- **Networking** — OSI/TCP-IP, subnetting, DNS/ARP/DHCP, scanning, MITM, packet analysis
- **Linux** — Filesystem, permissions, users, processes, SSH, bash, privilege escalation, logs
- **Recon & OSINT** — Methodology, passive/active recon, subdomain enum, infrastructure mapping
- **Web Application Security** — OWASP Top 10, auth, injection, SSRF/XXE, API testing
- **Tools Reference** — Nmap, Burp, Wireshark, Metasploit, BloodHound, Nuclei, Impacket
- **Privilege Escalation** — Linux & Windows: kernel, sudo/SUID, capabilities, tokens, DLL, UAC, Kerberos
- **Active Directory** — Kerberos, delegation, ACLs, AD CS, GPO, BloodHound, Azure AD
- **Cryptography** — TLS/certs, JWT, padding oracle, weak crypto, crypto in malware
- **Malware Analysis** — Static/dynamic, memory forensics, YARA, sandbox evasion, C2, ransomware
- **CTF Writeups** — Methodology-focused writeups from HTB, THM, competitions
- **Cloud Security** — AWS, Azure, GCP, containers/K8s, serverless
- **Wireless Security** — WPA2/3, evil twin, PMKID, Bluetooth, SDR
- **Mobile Security** — Android, iOS, Frida/Objection, bypassing controls
- **Appendices** — Ports, regex, file signatures, MITRE ATT&CK, glossary, certifications
